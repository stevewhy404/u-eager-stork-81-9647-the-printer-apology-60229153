# The Printer Apology

One line: an apology note from an office printer to the people who keep jamming it, feeding it cheap paper and swearing at it.

`main.py` writes the line to `/output/entry.txt` (UTF-8, 116 characters, one line).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
